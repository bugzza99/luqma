# Google Play store assets

Generated by `python brand/src/build_play_assets.py`. The script needs `pillow`,
`freetype-py`, `uharfbuzz`, and the brand font at `brand/src/Lemonada.ttf`.

| File | Size | Mode | Play requirement |
|---|---|---|---|
| `app_icon_512.png` | 512×512 | RGBA | 512×512 32-bit PNG, ≤ 1 MB |
| `feature-customer.png` | 1024×500 | RGB | 1024×500 24-bit PNG or JPEG, no alpha |
| `feature-merchant.png` | 1024×500 | RGB | 1024×500 24-bit PNG or JPEG, no alpha |

The icon is full-bleed burgundy; Play applies its own corner mask. The feature
graphics use the brand lockup and the same palette as the apps. The Arabic taglines
are shaped with HarfBuzz, because Pillow's text renderer has no Arabic shaping and
Lemonada has no precomposed presentation forms.

Screenshots are not generated here. They must be captured from the running apps;
see `docs/play-console/README.md`.
